강남 타임즈 텐프로, 일정이 바뀌면 다시 확인하세요

방문 계획을 세울 때는 일행과 약속한 시각과 실제 목적지에 도착할 수 있는 시각을 구분하는 것이 좋습니다. 일정이 바뀔 수 있다면 변경되는 항목부터 정리해 최신 안내를 다시 확인하세요.

실제 이용 가능 여부, 공간 구성, 비용과 예약 조건은 방문 전 공식 안내 페이지에서 확인해야 합니다.

1. 약속 시간과 도착 시간을 나누세요

식사나 다른 일정 뒤에 이동한다면 일행과 만나는 시간과 실제 도착 예정 시간이 다를 수 있습니다. 정확한 시간이 어렵다면 가능한 시간 범위를 전달하고 언제 최종 확인하면 되는지 알아두세요.

  • 일행과 약속한 시간
  • 실제 도착 예상 시간
  • 현재 확정 인원
  • 늦게 합류할 인원과 시간
  • 반드시 마쳐야 하는 시간

2. 먼저 도착하는 인원과 합류 인원을 구분하세요

전체 인원과 처음부터 함께 도착하는 인원을 나누어 확인하면 필요한 공간과 이용 조건을 더 명확하게 안내받을 수 있습니다. 아직 참석 여부가 정해지지 않은 인원은 확정 인원과 구분하세요.

늦게 합류하는 사람이 있다면 이용 시간이나 안내 조건에 영향이 있는지도 미리 확인하는 것이 좋습니다.

3. 마무리해야 하는 시간이 있다면 먼저 알리세요

다음 일정이나 귀가 계획으로 종료 시간이 정해져 있다면 상담할 때 함께 전달하세요. 이용 시작 기준과 예상 대기 여부, 해당 시간 안에 가능한 조건을 확인하면 일정 조율에 도움이 됩니다.

짧게 머문다고 비용이 같은 비율로 달라진다고 단정하지 말고, 실제 적용 기준을 별도로 확인하세요.

4. 변경된 항목부터 다시 안내받으세요

도착 시간이 늦어지거나 인원이 바뀌었다면 변경된 시간 또는 인원부터 전달하세요. 기존 예약이 유지되는지, 공간과 비용 조건이 달라지는지 최신 기준으로 확인해야 합니다.

날짜를 바꾸거나 취소해야 할 경우에는 필요한 절차와 적용 조건, 변경 후 예약이 새로 확정되었는지도 확인하세요.

5. 확정된 내용은 짧게 기록해 두세요

날짜, 인원, 도착 시간과 비용 안내의 기준을 함께 기록해 두면 이후 계획이 바뀌었을 때 무엇을 다시 확인해야 하는지 알기 쉽습니다. 일행에게도 확인된 내용과 확인 중인 내용을 구분해 공유하세요.

출발 전에는 예약 확정 상태, 최신 위치와 당일 안내를 다시 확인한 뒤 이동하세요.

최신 안내는 강남 타임즈 텐프로 공식 안내 페이지 에서 확인할 수 있습니다.
